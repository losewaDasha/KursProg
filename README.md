## Система мониторинга содержания примеси

## 1. Постановка задачи
Программа предназначена для мониторинга технологического процесса в реакторе по параметру «содержание примеси» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.
 
### Входные данные:
• Параметр X: содержание примеси, измеряется в %.
• Диапазон X: от -1 до 30 %.
• Нормальное состояние: штатный режим: 0–8 %; значения вне диапазона рассматриваются как отклонение технологического процесса.
• Количество измерений в выборке: N = 60. 

### Формула преобразования Q(X):
$$
Q(X) = 
\begin{cases} 
6\sqrt{X + 1} + 5, & \text{при } X < 0 \\
2(X - 4) + 50, & \text{при } 0 \le X \le 8 \\
0.25(X - 8)^2 + 55, & \text{при } X > 8 
\end{cases}
$$


**Ограничение:** Формула корректна при -1<=X<=30 (так как подкоренное выражение (X + 1) не может быть отрицательным, иначе получится 6 * sqrt(X+1) + 5). Значения X<1 математически некорректны и должны обрабатываться как ошибка ввода.

**Штатный режим** технологического процесса соответствует значениям входного параметра X, принадлежащий отрезку [0; 8].
При подстановке этих границ в формулу преобразования получаем значения для нормированного показателя качества: Q(0) = 42.0 и Q(8) = 58.0.
Таким образом, состояние процесса классифицируется как «Норма», если 42.0 <= Q(X) <= 58.0. В противном случае состояние классифицируется как «Отклонение».

### Ручной расчет (Примеры):
1. X = -1 (меньше 0):              Q = 6 * √(-1 + 1) + 5 = 6 * √0 + 5 = 5
2. X = 4.00 (в диапазоне 0-8):     Q = 2*(4.00 - 4) + 50 = 0 + 50 = 50.00
3. X = 10.00 (больше 8):           Q = 0.25(10.00 - 8)² + 55 = 0.25(2)² + 55 = 0.25*4 + 55 = 1 + 55 = 56.00

### Формат входных данных
Входной файл (например, `data.txt`) содержит последовательность чисел с плавающей точкой (вещественных чисел). Каждое число — это измеренное значение параметра X. Числа могут быть разделены пробелами, табуляцией или символами перевода строки.

### Интерфейс управления
Пользователь управляет программой через консольный ввод: при запуске программа запрашивает имя файла с данными. (Также реализована возможность передачи имени файла через аргументы командной строки). Если файл не существует или к нему нет доступа, программа сообщает об ошибке.

### Алгоритм потоковой обработки
Программа открывает файл и считывает данные по одному значению до достижения конца файла (EOF). Для каждой прочитанной записи выполняется следующий порядок действий:
1. **Прочитать X** из файла.
2. **Проверить ОДЗ:** Если X < -1, выводится сообщение об ошибке конкретной записи, и программа переходит к следующей (расчет не выполняется).
3. **Вычислить Q(X)** с использованием заданной кусочно-линейной функции.
4. **Выполнить контроль:** Проверить, попадает ли Q(X) в интервал [42.0; 58.0].
5. **Показать состояние:** Вывести на экран исходное X, рассчитанный Q(X) и вердикт («Норма» или «Отклонение»).

### Алгоритм
1) Начало.
2) Ввод данных: X
3) Задать условие: X < -1
4) Если X < -1: Ошибка -> конец
   Иначе:
5) Задать условие: X < 0
6) Если X < 0: Q = 6 * sqrt(X+1) + 5
   Иначе:
7) Задать условие: X <= 8
8) Если X <= 8: Q = 2(X-4) + 50
   Иначе: Q = 0.25(X-8)^2 + 55
9) Задать условие: 42 <= Q <= 58
10) Если 42 <= Q <= 58: Вывод: Норма
    Иначе: Вывод: Отклонение
11) Конец

### Блок-схема
```mermaid
graph TD
    Start([Начало]) --> Input[/Ввод X/]
    Input --> CheckX{"X >= -1 ?"}
    
    CheckX -- "Нет (Ошибка)" --> Error[Вывод ошибки]
    Error --> End([Конец])
    
    CheckX -- "Да" --> CalcQ[Расчет Q = f X]
    CalcQ --> CheckState{"|Q - 50.00| <= 10.0 ?"}
    
    CheckState -- "Да (<= 10)" --> StateNorm[STATE = 0<br/>Норма]
    CheckState -- "Нет (> 10)" --> StateDev[STATE = 1<br/>Отклонение]
    
    StateNorm --> OutputState[Вывод состояния]
    StateDev --> OutputState
    OutputState --> End
