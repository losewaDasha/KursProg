## Система мониторинга содержания примеси

### Постановка задачи
Программа предназначена для мониторинга технологического процесса в реакторе по параметру «содержание примеси» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.
 
### Входные данные:
• Параметр X: содержание примеси, измеряется в %.
• Диапазон X: от 0 до 30 %.
• Нормальное состояние: штатный режим: 0–8 %; значения вне диапазона рассматриваются как отклонение технологического процесса.
• Количество измерений в выборке: N = 60. 

### Формула преобразования Q(X):
 
                          6 * √(X - 0 + 1) + 5,      при X < 0
            Q(X)=         2(X – 4) + 50,             при 0 ≤ X ≤ 8
                          0.25(X – 8)² + 55,         при X > 8 
                          
### Ручной расчет (Примеры):
1. X = -1 (меньше 0):              Q = 6 * √(-1 - 0 + 1) + 5 = 6 * √0 + 5 = 5.00
2. X = 4.00 (в диапазоне 0-8):     Q = 2*(4.00 - 4) + 50 = 0 + 50 = 50.00 (Это ваш контрольный пример из задания 5)
3. X = 10.00 (больше 8):           Q = 0.25(10.00 - 8)² + 55 = 0.25(2)² + 55 = 0.25*4 + 55 = 1 + 55 = 56.00
