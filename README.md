## Система мониторинга содержания примеси

## 1. Постановка задачи
Программа предназначена для мониторинга технологического процесса в реакторе по параметру «содержание примеси» (X). Программа преобразует измеряемые значения в нормированный показатель качества Q(X), проводит оперативный контроль состояния процесса и статистический анализ выборки.
 
### Входные данные:
• Параметр X: содержание примеси, измеряется в %.
• Диапазон X: от 0 до 30 %.
• Нормальное состояние: штатный режим: 0–8 %; значения вне диапазона рассматриваются как отклонение технологического процесса.
• Количество измерений в выборке: N = 60. 

### Формула преобразования Q(X):
              Q(X) = \begin{cases}
              6\sqrt{X+1} + 5, & X < 0 \\
              2(X-4) + 50, & 0 \le X \le 8 \\
              0.25(X-8)^2 + 55, & X > 8
              \end{cases}


**Ограничение:** Формула корректна при X >= -1 (так как подкоренное выражение (X + 1) не может быть отрицательным, иначе получится 6 * sqrt(X+1) + 5). Значения X<=1 математически некорректны и должны обрабатываться как ошибка ввода.

**Штатный режим** технологического процесса соответствует значениям входного параметра X, принадлежащий отрезку [0; 8].
При подстановке этих границ в формулу преобразования получаем значения для нормированного показателя качества: Q(0) = 42.0 и Q(8) = 58.0.
Таким образом, состояние процесса классифицируется как «Норма», если 42.0 <= Q(X) <= 58.0. В противном случае состояние классифицируется как «Отклонение».

### Ручной расчет (Примеры):
1. X = -1 (меньше 0):              Q = 6 * √(-1 - 0 + 1) + 5 = 6 * √0 + 5 = 5.00
2. X = 4.00 (в диапазоне 0-8):     Q = 2*(4.00 - 4) + 50 = 0 + 50 = 50.00 (Это ваш контрольный пример из задания 5)
3. X = 10.00 (больше 8):           Q = 0.25(10.00 - 8)² + 55 = 0.25(2)² + 55 = 0.25*4 + 55 = 1 + 55 = 56.00

## 2. Алгоритм и блок-схема

### Алгоритм
1) Начало.
2) Ввод данных: Х
3) Задать условие: Х<=-1
4) Если Х<=-1:
   Ошибка -> конец
   
   Иначе:
5) Задать условие: X<0
6) Если  X<0:
   Q = 6 * sqrt(X+1) + 5
   
   Иначе:
7) Задать условие: Х<=8
8) Если Х<=8:
    Q = 2(X-4) + 50
    
   Иначе:
    Q = 0.25(X-8)^2 + 55
9) Задать условие: 42<=Q<=58
10) Если 42<=Q<=58:
    Вывод: Норма
    
    Иначе:
    Вывод: Отклонение
11) Конец
